# Bey Wallet ⚡🪙

![Bey Wallet](https://img.shields.io/badge/Status-Active_Development-blue?style=for-the-badge) ![Protocols](https://img.shields.io/badge/Protocols-Cashu_%7C_Lightning_%7C_Nostr-orange?style=for-the-badge)

**Bey** is a private, non-custodial Bitcoin and Cashu ecash wallet built for everyday micro-payments. By leveraging Chaumian blind signatures, Lightning network bridges, and Nostr integration, Bey delivers instant, private financial transactions without vendor lock-in.

---

## ✨ Key Features

*   **Private by Default (Cashu Ecash):** Utilizes blind-signed ecash tokens to ensure complete transaction privacy and untraceability across mints.
*   **Multi-Mint Support:** Connect, manage, and distribute ecash across multiple trusted mints from a single, unified interface.
*   **Diverse Payment Channels:** 
    *   **NFC Tap-to-Pay:** Exchange physical-style cash instantly by tapping two devices together.
    *   **QR & Lightning:** Bridge directly to the global Lightning network for instant settlement.
    *   **Nostr Addresses:** Send and receive funds natively via your `username@bey.cash` identifier.
*   **Deterministic Backups:** Secure recovery system allowing you to restore outstanding ecash balances using a standard 12-word recovery phrase.

---

## 🛠️ Technology & Protocols

Bey integrates modern open-source protocols to bridge sovereign digital currency with real-world utility:

*   **Bitcoin:** Base-layer settlement and security.
*   **Lightning Network:** High-speed routing and liquidity bridging via standard invoices.
*   **Cashu:** Chaumian ecash protocol providing cryptographic privacy guarantees.
*   **Nostr:** Decentralized identity and communication layer.
